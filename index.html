图像基础知识

图像基本概念

图像是人类视觉的基础，是自然景物的客观反映，是人类认识世界和人类本身的重要源泉。“图”是物体反射或透射光的分布，“像“是人的视觉系统所接受的图在人脑中所形成的印象或认识，照片、绘画、剪贴画、地图、书法作品、手写汉字、传真、卫星云图、影视画面、X光片、脑电图、心电图等都是图像。

在计算机中，按照颜色和灰度的多少可以将图像分为四种基本类型。

  • 二值图像

    一幅二值图像的二维矩阵仅由0、1两个值构成，“0”代表黑色，“1”代白色。由于每一像素（矩阵中每一元素）取值仅有0、1两种可能，所以计算机中二值图像的数据类型通常为1个二进制位。二值图像通常用于文字、线条图的扫描识别（OCR）和掩膜图像的存储。

  • 灰度图像

    灰度图像矩阵元素的取值范围通常为[0，255]。因此其数据类型一般为8位无符号整数的（int8），这就是人们经常提到的256灰度图像。**“0”表示纯黑色，“255”表示纯白色，中间的数字从小到大表示由黑到白的过渡色。**二值图像可以看成是灰度图像的一个特例。

  • 索引图像

    索引图像的文件结构比较复杂，除了存放图像的二维矩阵外，还包括一个称之为颜色索引矩阵MAP的二维数组。MAP的大小由存放图像的矩阵元素值域决定，如矩阵元素值域为[0，255]，则MAP矩阵的大小为256Ⅹ3，用MAP=[RGB]表示。MAP中每一行的三个元素分别指定该行对应颜色的红、绿、蓝单色值，MAP中每一行对应图像矩阵像素的一个灰度值，如某一像素的灰度值为64，则该像素就与MAP中的第64行建立了映射关系，该像素在屏幕上的实际颜色由第64行的[RGB]组合决定。也就是说，图像在屏幕上显示时，每一像素的颜色由存放在矩阵中该像素的灰度值作为索引通过检索颜色索引矩阵MAP得到。

  • 真彩色RGB图像

    RGB图像与索引图像一样都可以用来表示彩色图像。与索引图像一样，它分别用红（R）、绿（G）、蓝（B）三原色的组合来表示每个像素的颜色。但与索引图像不同的是，RGB图像每一个像素的颜色值（由RGB三原色表示）直接存放在图像矩阵中，由于每一像素的颜色需由R、G、B三个分量来表示，**M、N分别表示图像的行列数，三个M x N的二维矩阵分别表示各个像素的R、G、B三个颜色分量。**RGB图像的数据类型一般为8位无符号整形。注意：通道的顺序是 BGR 而不是 RGB。

    图像类型 通道数 像素值范围 主要特点 常见用途
    二值图像 1通道 0 或 1 每个像素只有黑与白两种值 形态学操作、二值化、轮廓检测
    灰度图像 1通道 0 到 255 每个像素表示灰度（亮度） 图像预处理、物体检测、人脸识别
    索引图像 1通道 0 到 255（索引） 像素值为颜色表的索引，颜色表决定实际颜色 存储压缩、较少颜色的图像表示
    RGB图像 3通道（R、G、B） 0 到 255 每个像素由红、绿、蓝三个通道组成 普通彩色图像显示、图像处理与分析

    简单的讲：图像是由像素点组成的，每个像素点的取值范围为: [0, 255] 。像素值越接近于0，颜色越暗，接近于黑色；像素值越接近于255，颜色越亮，接近于白色。

神经网络基础

post @ 2026-07-27

引言

这篇文章是我闲暇之余（实际上是在学习网安的过程中迷茫了）学习神经网络的笔记，跳过了机器学习的完整过程直接学习深度学习，目的是为了学完神经网络之后对AI学习以及网安学习产生一些新的思考

1.神经网络的发展

神经网络的发展并非一帆风顺的线性进步，而是一部充满高潮、低谷与颠覆性革命的曲折演进史，其思想萌芽可追溯至20世纪40年代，彼时麦克洛克和皮茨基于数理逻辑提出了首个形式化的M-P神经元模型，首次在数学层面模拟了生物神经元的“激活”机制，为整个领域奠定了最初的理论基石；

然而直到50年代末，罗森布拉特提出感知机（Perceptron）并成功将其应用于简单的模式识别，才真正点燃了第一波研究热潮，但这种单层结构的巨大缺陷很快暴露——它连最基本的异或（XOR）逻辑问题都无法解决，这一致命伤被马文·明斯基在1969年的著作中严厉抨击，直接导致神经网络研究在70年代几乎陷入万马齐喑的“第一次寒冬”。

进入80年代，随着反向传播（Backpropagation）算法被鲁梅尔哈特等人重新发现并推广至多层感知机，使得网络中间层（隐藏层）的错误信号能够有效回传并调整权重，这一突破极大地拓展了神经网络的非线性拟合能力，由此掀起了联结主义的第二次复兴，学界欢呼雀跃，认为机器智能的黎明即将到来；但好景不长，由于当时可用的数据规模极其有限，CPU算力捉襟见肘，更棘手的是，研究者发现当网络层数加深时，梯度信号在反向传播过程中会急剧消失或爆炸，导致深层网络几乎无法收敛，加之支持向量机（SVM）等浅层模型凭借精妙的核技巧和凸优化理论在性能上频频胜出，神经网络在90年代末期再次黯然失色，迎来了漫长的“第二次寒冬”。

真正的转机始于2006年，深度学习之父辛顿（Geoffrey Hinton）等人创新性地提出深度信念网络（DBN），通过无监督的逐层预训练策略有效缓解了梯度消失问题，并正式打出“深度学习”的旗帜，标志着第三次崛起的开端；

而引爆这场革命的标志性事件则是2012年的ImageNet图像识别竞赛，辛顿团队凭借深度卷积神经网络架构AlexNet，利用GPU并行计算处理海量数据，以碾压性的优势超越所有传统算法夺冠，向全世界证明了“深度+大数据+强算力”这一组合的惊人威力。自此，深度学习进入全面爆发时代，学界和工业界的热情如井喷般释放，研究者们不再畏首畏尾于网络的深度，反而不断堆叠层数，从经典的AlexNet到VGG、ResNet（残差网络）、Inception，网络动辄上百层甚至上千层；与此同时，神经网络的结构也在横向野蛮生长，从擅长处理序列数据的循环神经网络（RNN）及其改进型长短时记忆网络（LSTM）。

到2017年谷歌团队提出颠覆性的Transformer架构，彻底抛弃了传统的递归与卷积，仅依赖自注意力机制捕获全局依赖关系，这一革命性设计不仅将自然语言处理推向前所未有的高度，催生了GPT系列、BERT等千亿级参数量的大语言模型，更凭借其强大的扩展性和迁移能力反哺至计算机视觉、多模态融合乃至科学计算领域。如今，神经网络早已挣脱学术论文的束缚，深度嵌入到人脸识别、自动驾驶、蛋白质结构预测、AIGC（人工智能生成内容）乃至气象精准预报等千行百业，它从最初一个简单的数学模仿，经历两次寒冬的蛰伏与三次爆发的升腾，最终成长为当代人工智能无可争议的核心引擎，并且仍在以月为单位迭代进化，向着具身智能、世界模型等更宏大的未知疆域极速狂飙。
