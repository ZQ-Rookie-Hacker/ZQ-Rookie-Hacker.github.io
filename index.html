BloodHound食用

post @ 2026-03-23

1. 手册概述

BloodHound 是域渗透测试中核心的可视化分析工具，其预构建分析查询可精准定位域内高价值目标、攻击路径、高危权限配置与协议漏洞。本手册系统拆解所有预构建查询的核心用途、实战价值，并给出分阶段使用策略，帮助渗透测试人员高效利用查询结果规划攻击链路。

2. 预构建查询分类详解

2.1 域基础信息类（Domain Information）

查询名称 核心作用 实战价值 备注
Find all Domain Admins 列出Domain Admins组的所有成员 明确域内最高权限账号，锁定渗透最终目标 所有后续查询的核心参照目标
Map Domain Trusts 可视化域信任关系（父子域/外部域/林信任） 规划跨域渗透路径，找到从子域突破到父域的链路 需结合域控拓扑分析信任方向
Find Computers with Unsupported Operating Systems 查找运行已停止支持系统（Win7/2008/XP等）的主机 定位最易突破的初始攻击入口（漏洞多、补丁少） 优先作为初始打点的目标清单

2.2 危险权限类（Dangerous Privileges）

查询名称 核心作用 实战价值 备注
Find Principals with DCSync Rights 查找拥有DCSync权限的主体（用户/组/计算机） 拿到该权限可直接同步所有域账号哈希，控制整个域 域内最高危权限，优先级最高的攻击目标
Users with Foreign Domain Group Membership 查找属于外部域组的用户 作为跨域攻击入口，利用用户在其他域的权限突破边界 需结合域信任关系分析权限传递
Groups with Foreign Domain Group Membership 查找包含外部域成员的组 利用组权限传递特性，实现跨域横向渗透 重点关注高权限组（如管理员组）的外部成员
Find Computers where Domain Users are Local Admin 查找普通域用户为本地管理员的主机 横向移动核心入口，拿到主机权限后窃取高权限凭证 优先对这类主机进行横向打点
Find Computers where Domain Users can read LAPS passwords 查找可读取LAPS密码的主机 直接获取主机本地管理员权限，无需破解 LAPS为本地管理员密码管理工具，是高价值目标
Find All Paths from Domain Users to High Value Targets 生成从普通域用户到高价值目标的完整攻击路径 渗透核心导航，明确“从哪台机、用哪个账号”提权 初始渗透阶段首选查询
Find Workstations where Domain Users can RDP 查找普通用户可RDP的工作站 直接登录后提权、窃取凭证 优先选择核心业务人员的工作站
Find Servers where Domain Users can RDP 查找普通用户可RDP的服务器 服务器承载关键服务，易接触高权限账号 重点关注数据库、应用服务器
Find Dangerous Privileges for Domain Users Groups 查找域用户组的危险特权（如SeImpersonatePrivilege） 利用特权实现本地提权，获取系统权限 结合提权工具（如JuicyPotato）使用
Find Domain Admin Logons to non-Domain Controllers 查找域管理员登录过的非域控主机 窃取这些主机的凭证可直接拿到域管权限 最稳定的提权方式之一，优先分析

2.3 Kerberos 协议类（Kerberos Interaction）

查询名称 核心作用 实战价值 备注
Find Kerberoastable Members of High Value Groups 查找高价值组中可被Kerberoasting攻击的成员 优先攻击高权限服务账号，提升提权效率 高价值组包括域管组、企业管理员组等
List all Kerberoastable Accounts 列出所有带SPN的用户/服务账号 发起Kerberoasting攻击，离线破解NTLM哈希 需结合Impacket等工具请求服务票据
Find Kerberoastable Users with most privileges 查找权限最高的可Kerberoasting用户 精准定位高价值攻击目标，减少无效破解 结合权限图谱分析用户所属组
Find AS-REP Roastable Users (DontReqPreAuth) 查找无需Kerberos预认证的用户 发起AS-REP Roasting攻击，直接获取NT哈希 攻击门槛极低，无前置权限也可执行

post @ 2026-02-02

一、核心框架升级

核心阵营 核心定位 代表工具 核心解决的问题 安全场景优先级
包管理工具 软件全生命周期管理（安装/更新/卸载/依赖） dpkg、apt、gdebi-core、rpm、yum、dnf、flatpak、snap 系统工具部署、CTF环境搭建、漏洞复现依赖处理 🌟🌟🌟🌟🌟（核心必备）
通用网络文件传输工具 网络文件/数据传输（拉取/推送） wget、curl 漏洞利用脚本下载、靶机文件上传、接口测试 🌟🌟🌟🌟🌟（渗透核心）
包管理配套辅助工具 包管理优化（查询/配置/清理） aptitude、synaptic、dpkg-reconfigure、apt-mark、yum-utils 工具版本锁定（CTF兼容）、依赖清理（避免暴露痕迹） 🌟🌟🌟🌟（实战常用）

安全核心原则：

  1. 渗透测试中「优先使用本地包安装工具」（避免依赖仓库暴露网络痕迹）；
  2. 服务器配置中「用apt-mark锁定工具版本」（防止自动升级导致漏洞复现失败）；
  3. 网络传输优先用「wget/curl的无痕迹参数」（如忽略SSL证书、禁用日志）。

二、第一阵营：包管理工具

（一）Debian系

1. 底层工具：dpkg

  • 安全实战场景：渗透测试中，通过dpkg -L 软件名查询工具安装路径（如Hydra、Nmap），便于调用二进制文件或修改配置；
  • 常见错误修复：
    • 安装deb包时提示“权限不足”：sudo dpkg -i 包名.deb（加sudo避免权限问题）；
    • 安装失败后无法重新安装：sudo dpkg --purge 软件名（彻底清理残留，再重新安装）。

  • 渗透测试避坑点：apt update会联网获取仓库信息，可能暴露靶机IP，无网络场景下禁用，直接用本地包安装。

Kali右键菜单添加

post @ 2025-12-25

🔍 核心原理

项目 正确做法 错误做法
安装路径 通过官方脚本安装到 /usr/bin/ 安装到 ~/.cargo/bin/（需额外配置 PATH）
文件位置 移动到 ~/.local/share/applications/ 保留在桌面或 /usr/share/
Categories 标签 kali-reconnaissance;kali-network-information;kali-network-service-discovery; Security; 或 kali-network-service-discovery;（缺少 kali-network-information）
图标 Icon=system-run kali-rustscan（不存在）
命令格式 Exec=xfce4-terminal -e "bash -c 'read -p \"IP: \" ip; rustscan -a $ip -- -sV; read -p \"按 Enter 键退出\"'" rustscan --help（只显示帮助）

📌 5 步操作

✅ 步骤 1：通过 GitHub 安装 rustscan（官方脚本）

✅ 验证安装：

which rustscan
# 预期输出：/usr/bin/rustscan

rustscan --version
# 预期输出：2.1.1（或最新版本）

💡 关键原理：

  • 安装脚本会自动将二进制文件放到 /usr/bin/（Linux 标准 PATH 路径）
  • 无需手动配置 PATH，系统自动识别命令

✅ 步骤 2：在桌面创建启动器

  1. 右键桌面空白处 → 选择 “创建启动器(L)…”
  2. 填写信息：一般会自动填充

✅ 步骤 3：移动文件到正确目录

✅ 验证目录：

ls -ld ~/.local/share/applications
# 预期输出：drwxr-xr-x 2 ... /home/rookie-hacker/.local/share/applications

✅ 步骤 4：修正 Categories 标签

✏️ 修改内容：

# 现在查看右键菜单中其他快捷方式的格式
cat /usr/share/applications/xxx.desktop
# 找到 Categories 行，替换为精准标签
Categories=kali-reconnaissance;kali-network-information;kali-network-service-discovery;

✅ ‘完整’配置示例：

[Desktop Entry]
Version=1.0
Type=Application
Name=
Comment=
Exec=
Icon=system-run
Terminal=true
Type=Application
Categories=kali-reconnaissance;kali-network-information;kali-network-service-discovery; # 主要修改这里，其他在创建启动器的时候会自动填充
StartupNotify=false

✏️ 保存并退出：

  • ：wq

✅ 步骤 5：刷新菜单缓存

⚠️ 常见错误解决方案

问题 原因 解决方案
which rustscan 无输出 安装失败 重新执行安装脚本：curl -s https://raw.githubusercontent.com/RustScan/RustScan/master/script/install.sh | sudo bash
移动时报错 “不是目录” ~/.local/share/applications 是文件 执行 rm -f ~/.local/share/applications 再重建目录
菜单只在”网络扫描”显示 缺少 kali-network-information 标签 用 sed 修正 Categories 行：sed -i 's/Categories=.*/Categories=kali-reconnaissance;kali-network-information;kali-network-service-discovery;/' ~/.local/share/applications/rustscan.desktop
终端报错 rustscan: command not found PATH 未包含 /usr/bin/ 执行 echo 'export PATH="$PATH:/usr/bin"' >> ~/.zshrc && source ~/.zshrc
图标不显示 未使用 system-run 确保 Icon=system-run（不是 kali-rustscan）

DIV与CSS基础详解

post @ 2025-12-18

1. DIV和CSS样式

详细解释：

  • DIV 是HTML中的一个块级元素，用于将文档分割为独立的区块。它本身没有特定的语义，主要作为容器使用，通过CSS来定义其外观和布局。
  • CSS（层叠样式表）是一种描述HTML或XML文档外观和格式的样式表语言。CSS的核心理念是将内容与表现分离，使网页结构更清晰、更易于维护。

为什么使用DIV+CSS：

  • 与传统的表格布局相比，DIV+CSS布局更加灵活、代码更简洁
  • 提高网页加载速度（减少冗余HTML标签）
  • 更好的SEO优化（搜索引擎更容易抓取内容）
  • 便于后期维护和修改
